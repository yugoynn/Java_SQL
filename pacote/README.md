# Projeto

Projeto Java com conexão PostgreSQL.

## Estrutura
- `src/` → código Java
- `database/` → scripts SQL
- `docs/` → documentação

projeto-faculdade/
├── src/
│   ├── Main.java        ← entrada do programa
│   └── ConexaoDB.java   ← conexão com o banco
├── database/
│   └── tabelas.sql      ← script pra criar as tabelas
├── docs/                ← documentação (vazio por enquanto)
├── .gitignore
└── README.md
